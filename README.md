# 📊 Financial Operations Analytics

### Exploratory Data Analysis for Business Performance and Customer Insights

## 📌 Project Overview

Financial Operations Analytics is a data analytics project focused on understanding business performance through account information, subscriptions, customer churn, feature usage, and customer support data.

The objective is to explore business datasets, analyze key performance indicators (KPIs), and identify insights that can support data-driven decision-making.

## 🎯 Business Objectives

* Analyze account and subscription performance.
* Understand customer churn patterns.
* Evaluate feature adoption and usage.
* Examine customer support activity.
* Identify data quality issues.
* Analyze business performance using relevant KPIs.

## 📂 Datasets

The project includes five datasets:

| Dataset       | Description                        |
| ------------- | ---------------------------------- |
| Accounts      | Account-level information          |
| Subscriptions | Subscription records and activity  |
| Churn         | Customer churn-related information |
| Feature Usage | Feature adoption and usage         |
| Support       | Customer support interactions      |
